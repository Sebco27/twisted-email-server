# e-Mail

Basic implementation of an email system using Python and the Twisted library.

## Features

* SMTP server for sending and receiving emails
* POP3 server
* XMPP notifications for new emails
* TLS/SSL support for secure communication


## Requirements

* Python
* Twisted
* GNU/Linux
